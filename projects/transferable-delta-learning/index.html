02 · Target design

Delta Learning for Transferable Molecular Models

Treating the learning target as a design choice: selecting physical baselines that remove difficult target components and expose smoother residuals to a molecular model.

  • Delta Learning
  • Target Design
  • Molecular GNNs
  • Transferability

Research question

Why do some delta-learning models transfer across chemical space while others improve only in distribution? Model capacity and dataset size are not sufficient explanations. Transferability also depends on whether the selected physical baseline removes target components that are difficult for the model to represent.

Delta learning as target design

A low-cost physical method supplies a baseline prediction, and machine learning predicts the correction required to approach a higher-fidelity quantum-chemical target. The final prediction combines both contributions.

High-fidelity prediction = physical baseline + learned residual

This viewpoint makes baseline choice part of the model architecture. A useful baseline does more than correlate with the target: it reshapes the residual's smoothness, variance, and dependence on molecular structure so the remaining mapping better matches the model's inductive bias.

Evaluation strategy

The project compares baseline-to-DFT correction problems across chemical spaces, examining in-distribution accuracy together with transfer to molecules unlike those used for training. Analysis focuses on target distributions, feature-target mappings, residual complexity, and the conditions under which a lower-cost physical model produces a genuinely more learnable target.

Research objective

The goal is a practical set of design principles for hybrid physics-machine-learning models: how to select a baseline, how to diagnose target alignment, and when delta learning should improve data efficiency and out-of-distribution performance in molecular and materials prediction.
