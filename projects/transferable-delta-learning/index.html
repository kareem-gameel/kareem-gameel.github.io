02 · Target design

The Mechanics of Delta Learning

Target design for generalizable scientific machine learning through normalized residual roughness and complementary physical baselines.

  • Delta Learning
  • Target Design
  • Molecular GNNs
  • Transferability

Research question

Why do some delta-learning models transfer across chemical space while others improve only in distribution? Model capacity and dataset size are not sufficient explanations. Transferability also depends on whether the selected physical baseline removes target components that are difficult for the model to represent.

Delta learning as target design

A low-cost physical method supplies a baseline prediction, and machine learning predicts the correction required to approach a higher-fidelity quantum-chemical target. The final prediction combines both contributions.

High-fidelity prediction = physical baseline + learned residual

This viewpoint makes baseline choice part of the model architecture. A useful baseline does more than correlate with the target: it reshapes the residual's smoothness, variance, and dependence on molecular structure so the remaining mapping better matches the model's inductive bias.

Evaluation strategy

We compare baseline-to-DFT correction problems across chemical spaces using molecular graph neural networks, evaluating both in-domain accuracy and transfer to molecules unlike those used for training. Scale-normalized graph Dirichlet roughness provides a pre-training diagnostic of residual learnability.

Central finding

Smaller residuals are not necessarily easier to learn. Complex local baselines can produce low-scale but disproportionately rough targets, whereas a complementary semi-empirical baseline reduces both scale and normalized roughness. Baseline choice is therefore a target-design decision, not simply an accuracy ranking among low-cost methods.
